# Phone Store

Phone e-commerce store with a React frontend and a Node.js backend API.

## Structure

```text
web/   React frontend
api/   Node.js, Express and MySQL backend API
```

## Getting started

Run the API and the web app in two terminals:

```bash
cd api && npm install && npm start
```

```bash
cd web && npm install && npm start
```

Copy any `.env.example` file to `.env` in the same folder and fill in your own values before starting.
